网站屏蔽检测

检测 Cloudflare Radar Top 网站在当前网络下是否被 HDSB 屏蔽

本软件支持安卓、Windows、macOS、Linux。 为什么不支持 iOS 因为我买不起 App Store 证书喵。
所以各位苹果人朋友想要检测的话可以打开电脑，或者借用一下旁边安卓人的手机了。

前往 GitHub 下载屏蔽检测软件

macOS 提示「已损坏」怎么办

从 GitHub 下载的应用没有 Apple 签名，macOS 会提示「已损坏，无法打开」。这并不代表文件损坏，在「终端」中执行下面这条命令即可解除限制（把路径换成实际的应用）： 

xattr -cr "/Applications/你的应用.app"

也可以打开「系统设置 → 隐私与安全性」，在底部找到被拦截的提示，点击「仍要打开」。

网页版检测受浏览器跨域（CORS）限制，结果不够可靠。推荐下载独立的屏蔽检测软件，获得更准确、更全面的检测结果。

关于检测

HDSB 会在网络出口拦截并篡改对部分网站的访问。检测软件会逐一访问 Cloudflare Radar Top 榜单中的网站，判断其是否被拦截，帮助你了解当前网络下的可访问情况。

可以做什么
  • 批量检测 Cloudflare Radar Top 榜单网站的可访问性
  • 区分「可访问 / 被屏蔽 / 无法访问 / 超时」并统计数量
  • 查看每个域名的判定详情，并导出结果为 CSV
如何判断被屏蔽

当请求被 HDSB 拦截时，通常会返回其拦截页面，或把网站证书替换为拦截设备签发的证书。检测软件会据此判断网站是否被屏蔽。

使用提示
  • 请在 HDSB 网络环境下运行，检测结果才有意义
  • 不同时间、不同网络下结果可能不同，仅供参考
  • 检测会请求大量域名，首次运行可能需要一些时间
